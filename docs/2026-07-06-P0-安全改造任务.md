# P0 — 安全改造任务

| 字段 | 内容 |
|------|------|
| 阶段 | P0（必须先做） |
| 目标 | 后端 API 强制角色 + 分会范围隔离；修复 ScopeService；管理端登录与 CMS JWT 角色统一 |
| 关联 PRD | [2026-07-05-后台管理角色说明-PRD.md](./2026-07-05-后台管理角色说明-PRD.md) §4、§7.3 |
| 涉及仓库 | `paleontology-cms-backend`、`paleontology-admin-latest` |
| 预估工作量 | 3–5 人日 |
| 前置依赖 | 无 |
| 阻塞 | P1、P2 全部依赖本阶段 |

---

## 阶段目标

1. 管理员账号与分会绑定落库，不再仅依赖前端 `BUILT_IN_ADMINS` 硬编码。
2. 管理端登录后，CMS JWT 中的 `role` / `branchId` 与真实登录账号一致（消除 `ensureCmsAuth()` 写死 `admin/admin123`）。
3. 修复 `CmsScopeService` 中 `association_id`（Long）与 `branch_code`（String）混比问题，并抽成统一 `AdminScopeService`。
4. 会员、会议、统计等**管理端 API** 在后端强制过滤，不可仅靠前端隐藏菜单绕过。

---

**优先级**：P0 / 阻塞项  
**预估**：0.5 人日  
**负责模块**：`paleontology-cms-backend`

#### 子任务

| ID | 任务 | 说明 |
|----|------|------|
| P0-1a | 编写 Flyway `V23__admin_accounts_and_association.sql` | 扩展 `cms_admin_user`；新建 `paleo_admin_association` |

#### 表结构要点

**`cms_admin_user` 扩展字段**

| 字段 | 类型 | 说明 |
|------|------|------|
| `email` | VARCHAR(128) UNIQUE | 登录邮箱，与前端一致 |
| `role` | VARCHAR(32) | `super_admin` / `branch_admin` / `finance_reviewer` |
| `branch_code` | VARCHAR(32) NULL | 分会管理员必填，如 `gjzdw` |

**`paleo_admin_association`**

| 字段 | 类型 | 说明 |
|------|------|------|
| `binding_id` | BIGINT PK | 自增 |
| `admin_user_id` | BIGINT | 关联 `cms_admin_user.user_id` |
| `association_id` | BIGINT | 关联 `paleo_association.association_id` |
| `binding_status` | VARCHAR(20) | `BOUND` / `UNBOUND` |

#### 种子账号（与 PRD §六 对齐）

| 邮箱 | role | branch_code |
|------|------|-------------|
| `admin@paleontology.org.cn` | `super_admin` | — |

| …（其余 10 个分会） | `branch_admin` | 对应编码 |
| `branch_gjzdw@paleo.org.cn` | `branch_admin` | `gjzdw` |

| P0-2a | 扩展 `AuthController` | 支持邮箱+密码登录（或 `POST /admin/login`）；返回 token、role、branchCode、displayName |
| P0-2b | JWT Payload | `LoginUser` 写入真实 `role`、`branchId`（branch_code） |
| P0-2c | 改造 `LoginPage.tsx` | 登录成功后 `cmsLogin(email, password)`，删除硬编码 |

```typescript
}
```

- [ ] 后端审核 API 的操作者可追溯到真实登录账号（非统一 `admin`）

### P0-3 修复并统一 ScopeService

**优先级**：P0 / 阻塞项

#### 子任务

| ID | 任务 | 说明 |
|----|------|------|
| P0-3a | 新建 `PaleoAssociationCodeService` | `branchCode ↔ associationId` 双向映射（读 `paleo_association.branch_code`） |
| P0-3b | 新建 `AdminScopeService` | 统一范围判定，替代/包装 `CmsScopeService` |
| P0-3c | 重构 CMS 控制器 | `PaleoCmsEntryController`、`PaleoCmsChannelController` 改用 `AdminScopeService` |

#### AdminScopeService 接口草案

```java
boolean isSuperAdmin(LoginUser user);
boolean isFinanceReviewer(LoginUser user);
boolean isBranchAdmin(LoginUser user);
boolean canAccessBranchCode(LoginUser user, String branchCode);
boolean canAccessAssociationId(LoginUser user, Long associationId);
List<Long> resolveAccessibleAssociationIds(LoginUser user);
```

#### 角色范围规则

| 角色 | 数据范围 |
|------|---------|
| `super_admin` | 全站 |
| `finance_reviewer` | 全站（写操作另在 P1 限制） |
| `branch_admin` | 仅 `paleo_admin_association` 绑定的分会 |
| 未登录 / 未知 | 拒绝 |

#### 需修复的 Bug

```java
// CmsScopeService — 错误：Long 与 branch_code 字符串比较
return String.valueOf(associationId).equals(user.getBranchId());
// 应改为：branchCode 映射后再比较
```

#### 验收标准

- [ ] 分会管理员 JWT `branchId=gjzdw` 时，访问 `association_id=8` 通过，访问 `association_id=2` 拒绝
- [ ] CMS 内容读写隔离回归通过
- [ ] 单元测试覆盖三种角色 + 边界 case

### P0-4 业务 API 加角色 + 分会范围拦截

**优先级**：P0 / 核心  
**预估**：1.5–2 人日  
**依赖**：P0-2、P0-3  
**负责模块**：`paleontology-cms-backend`

#### 子任务

| ID | 任务 | 说明 |
|----|------|------|
| P0-4a | 角色注解 / 拦截器 | `@RequireAdminRole` 或 `AdminRoleInterceptor` |
| P0-4b | 会员管理 API 范围 | directory、applications、payments 的 list/review |
| P0-4c | 会议报名 API 范围 | registrations list/review/pending |
| P0-4d | 统计 API 范围 | `/paleo/dashboard/stats` |
| P0-4e | 写操作校验 | review、代改等操作前 `assertCanAccess*` |

#### 需拦截的管理端路径

| 模块 | 路径 | 范围规则 |
|------|------|---------|
| 会员 | `/paleo/membership/admin/**` | 财务+总管理员：全站；分会：按绑定分会过滤用户 |
| 会员 | `/paleo/membership/applications/list`、`/*/review` | 仅 `super_admin`（入会/退会在 P1 再收紧财务） |
| 会员 | `/paleo/membership/payments/list`、`/*/review`、`/reviews/**` | 财务+总管理员：全站 |
| 会议 | `/paleo/conferences/registrations/list`、`/*/review`、`/reviews/**` | 财务+总管理员：全站；分会：本分会会议 |
| 统计 | `/paleo/dashboard/stats` | 分会：本分会聚合 |

#### Service 层补充

| Service | 方法 |
|---------|------|
| `PaleoMembershipDirectoryService` | `listDirectoryForAdmin(LoginUser user)` |
| `PaleoConferenceRegistrationService` | `listForAdmin(LoginUser user, filters)` |
| 通用 | `assertCanAccessRegistration(user, registrationId)` |

#### 验收标准（PRD §7.3 核心）

- [ ] 分会管理员直接调 API 无法获取其他分会 `registrationId` 详情（403 或空集）
- [ ] 财务账号可调全站 pending 缴费列表
- [ ] 财务账号调 CMS 写接口返回 403
- [ ] 无 token 访问管理路径返回 401
- [ ] Postman/脚本：3 角色 × 跨分会访问 = 403 用例集
