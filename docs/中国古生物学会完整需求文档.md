## 1. 项目概述

### 1.1 项目背景

中国古生物学会及其下属 11 个专业分会需建设统一的新网站及会员管理系统，以支撑学会日常运营，重点解决：

- 会员注册、会费缴纳、会员资格管理的线上化
- 学术会议从发布到参会报名的全流程管理
- 党建文化内容的规范化展示与维护
- 满足审计整改要求，实现财务对账清晰、凭证发票可追溯

上级领导明确要求**优先做好两项核心能力**：**会员服务**（注册、会费、会议费、参会信息）与**党建文化**。其余栏目在既有官网模块基础上扩充调整。网站外观参考中国环境科学学会官网风格；后期可由科学传播老师调整视觉，但不影响基础架构。

### 1.2 核心设计原则

| 原则 | 说明 |
|------|------|
| **单账号全局通用** | 一个邮箱对应一个账号，全站所有学会单元通用 |
| **邮箱实名验证** | 注册时须通过**邮箱验证码**确认邮箱归属，验证码校验通过后方可完成注册 |
| **双路径会员体系** | 首次登录后自主选择：非会员（无需会费，会议费较高）或正式会员（须完成入会全流程，享会员价） |
| **统一会员身份** | 正式会员身份为「中国古生物学会会员」，**会员费只收取一次**，不因绑定多个分会重复收费 |
| **分会自由绑定** | 非会员和正式会员均可自由绑定/解绑多个分会（0~11 个）；绑定决定可见会议与通知 |
| **总学会独立运营** | 总学会与 11 个分会在统计、收支、会议发布上**独立拆分**，各有收入与支出 |
| **会议一场一缴** | 会议费按每场会议单独缴纳；参加几场缴几次；**一次只能缴纳一个会议的注册费** |
| **两阶段财务审核** | 缴费分为凭证初审、发票终审；符合所财务单笔核对习惯 |
| **智能识别 + 人工兜底** | 凭证/发票上传后先 OCR 识别比对，再进入人工审核队列；秘书处无法逐笔人工核验全部 |
| **提交后锁定** | 验证通过后用户不可自行修改；须管理员**手动驳回**后方可重传 |
| **最新版本原则** | 参会信息、摘要 Word 只保留最后一次更新版本 |
| **野外路线不代收** | 不设计会前/会中/会后野外收费；仅提供旅游公司公告与路线选择；费用由旅游公司收取 |
| **CMS 直接发布** | 管理员直接发布内容，**无多人审批流**；支持逻辑下线 |
| **服务端持久化** | 用户、缴费、会议、报名、参会信息、通知等核心业务数据须入库，前后台状态一致 |

### 1.3 整体业务逻辑

```
邮箱验证码注册 → 首次登录 → 选择参与方式
  ├── 路径 A：非会员 → 绑定分会 → 报名会议（非会员价 = 会员价 × 1.1）
  └── 路径 B：正式会员 → 提交入会申请书 → 秘书处审核
        → 缴纳统一会员费（凭证 → 发票，两阶段）
        → 成为正式会员（有效期 1 年）
        → 绑定分会 → 报名会议（会员价）

会员到期 → 身份降为非会员 → 分会绑定保留 → 会议资格分级处理
退会 → 秘书处审核 → 当日终止会员资格 → 可重新申请入会（无需解锁）
```

## 2. 系统架构

### 2.1 逻辑架构

```
┌─────────────────────────────────────────────────────────────┐
│                        用户层                                │
│   访客  │  注册用户（普通/非会员/正式会员）  │  管理员        │
└─────────┬───────────────────────┬───────────────────────────┘
          │                       │
┌─────────▼─────────┐   ┌─────────▼─────────┐
│   学会主站（前台）   │   │   管理后台         │
│ 内容浏览 + 业务办理  │   │ CMS + 审核 + 统计  │
└─────────┬─────────┘   └─────────┬─────────┘
          │                       │
          └───────────┬───────────┘
                      │
          ┌───────────▼───────────┐
          │   业务后端 API           │
          │ 认证 / 会员 / 会议 / CMS │
          └───────────┬───────────┘
                      │
          ┌───────────▼───────────┐
          │   MySQL 数据库         │
          │ 用户 / 缴费 / 内容 / 审计│
          └───────────────────────┘
```

### 2.2 模块职责

| 组成部分 | 职责 |
|----------|------|
| **学会主站** | 顶栏导航、学会服务（会员/会议）、个人中心、党建子系统、CMS 动态页面渲染 |
| **管理后台** | 内容发布、栏目编排、入会/退会/缴费审核、会员名录、会议管理、统计导出、审计查询、数据权限 |
| **业务后端** | REST API、状态机、权限校验、审计落库、仪表盘聚合、文件存储 |

### 2.3 技术架构要求

| 层次 | 要求 |
|------|------|
| **学会主站** | 响应式 Web 应用；内容页 CMS 驱动；会员/会议业务与后端 API 交互 |
| **管理后台** | 基于 RuoYi 框架；菜单权限与数据范围隔离；CMS、审核、统计、导出一体化 |
| **业务后端** | REST API；统一鉴权（JWT）；会员/会议状态机；审计落库；仪表盘实时聚合 |
| **数据库** | MySQL；**全部业务数据须服务端持久化**（用户、缴费、会议、报名、参会信息、通知、审计等） |
| **文件存储** | 使用对象存储（如阿里云 OSS）；凭证、发票、摘要、公开文件统一管理 |
| **邮件服务** | 企业邮箱或第三方邮件服务（如 SendCloud）；支撑注册验证码、忘记密码、业务通知 |
| **缓存与安全** | Redis（JWT 黑名单、验证码、频率限制）；HTTPS；敏感操作审计 |

**数据原则**：不允许将会员状态、会议报名、参会信息、缴费记录、统计结果等核心业务数据仅保存在浏览器本地；前后台对同一用户须展示一致的业务状态。

### 7.1 注册规则

| 字段 | 要求 |
|------|------|
| 邮箱 | 必填，全局唯一，**不可修改**，作为登录账号 |
| 密码 | 必填，≥ 6 位 |
| 确认密码 | 必填，须一致 |
| 姓名 | 必填，实名制（供凭证识别核对） |
| 性别 | 必填 |
| 单位 | 必填 |
| 职务/身份 | 选填：学生、教师、其他、职称 |

**注册须先完成邮箱验证码校验**（详见 §7.2），验证通过后方可提交注册表单并创建账号。

注册成功 → 提示登录 → 首次登录后须完成会员路径选择。

### 7.2 邮箱验证码验证

注册流程须增加**邮箱验证码**环节，用于确认用户拥有该邮箱、降低虚假注册与误填邮箱风险。

#### 7.2.1 注册流程

```
填写邮箱 → 点击「获取验证码」→ 系统发送邮件
  → 用户输入验证码 → 校验通过
  → 填写密码、姓名等其余字段 → 提交注册 → 注册成功
```

#### 7.2.2 发送规则

| 项目 | 要求 |
|------|------|
| 触发 | 用户点击「获取验证码」；须先填写合法格式邮箱 |
| 发送渠道 | 邮件服务（企业邮箱 / SendCloud 等，与 §15.2 邮件能力共用） |
| 验证码形式 | 数字验证码，建议 **6 位** |
| 有效期 | **5~10 分钟**（可后台配置，默认 10 分钟） |
| 邮件内容 | 说明用途（注册验证）、验证码、有效期、勿泄露提示；学会署名 |
| 未注册邮箱 | 允许发送；若邮箱已注册则提示「该邮箱已注册」并**不发送**验证码 |

#### 7.2.3 校验规则

| 项目 | 要求 |
|------|------|
| 提交注册前 | **必须**通过验证码校验；未验证或已过期不可提交 |
| 验证码错误 | 提示剩余可尝试次数 |
| 验证码过期 | 提示重新获取 |
| 验证码使用后 | **立即失效**，不可重复使用 |
| 邮箱与验证码 | 须绑定同一邮箱；换邮箱须重新获取验证码 |

#### 7.2.4 频率限制（防滥用）

| 限制项 | 建议值 |
|--------|--------|
| 同一邮箱发送间隔 | ≥ 60 秒 |
| 同一邮箱每日上限 | ≤ 10 次 |
| 同一 IP 每日上限 | ≤ 30 次（可配置） |
| 连续校验失败 | 5 次失败后锁定该邮箱 **15 分钟**再允许重新获取 |

#### 7.2.5 与忘记密码的关系

- **注册验证码**与**忘记密码验证码**使用独立业务类型，不可混用
- 忘记密码流程同样须邮箱验证码（或重置链接），规则参考本节；统一邮件服务发送

#### 7.2.6 后台与审计

- 管理端可查看验证码发送日志（邮箱、时间、IP、成功/失败），**不展示明文验证码**
- 注册成功写入审计或业务日志（不含验证码）

### 7.3 登录

- 邮箱 + 密码登录
- 账号可被后台禁用，禁用后无法登录
- 忘记密码：通过邮箱验证码或重置链接完成，须接入邮件服务

|------|------|

## 9. 入会、退会与正式会员认定

### 9.1 正式会员认定标准

须**依次**完成以下三步且均被审核通过，方认定为**正式会员**，计入后台「正式会员」统计：

```
① 入会申请书 → 秘书处审核通过
② 会费缴纳凭证 → 财务审核通过
③ 会费发票 → 财务审核通过 → 会员资格有效（active）
```

中间状态用户归入「**入会办理中**」，不计入正式会员。

### 9.2 入会申请书（0617 新增）

| 项目 | 规则 |
|------|------|
| 适用对象 | 选择正式会员路径的用户；**学生与非学生均须提交** |
| 文件格式 | Word（.doc/.docx）或 PDF |
| 大小 | ≤ 20MB |
| 模板 | 后台维护入会申请书 Word 模板，用户可下载 |
| 待审核 | 可取消；不可重复提交同类型待审核申请 |
| 审核方 | **学会总管理员（秘书处）** |
| 驳回 | 须填原因，用户可重新提交 |

### 9.3 退会机制（0617 新增）

| 项目 | 规则 |
|------|------|
| 适用对象 | 仅**会员资格有效**的用户 |
| 材料 | 电子版退会申请书（必传）；模板由管理员上传 |
| 审核方 | 学会总管理员 |
| 审核通过 | **当日**终止会员资格；身份变为非会员；会费记录作废处理 |
| 待审核 | 可取消退会申请 |
| 退会后 | **分会绑定保留**；可按非会员价参会 |
| 超期未续费 | 视为自动失效/退会，保留历史，可按非会员继续使用 |
| 再次入会 | **无需管理员解锁**（0626 确认），直接重新提交入会申请 |

### 9.4 入会完整流程图

```
注册 → 首次登录选择「正式会员」
  → 下载模板 → 上传入会申请书
  → 秘书处审核
      ├── 驳回 → 修改重提
      └── 通过 → 上传会费凭证
          → 财务审核凭证
              ├── 驳回 → 重传凭证
              └── 通过 → 上传发票（7 工作日内）
                  → 财务审核发票
                      ├── 驳回 → 重传发票
                      └── 通过 → 正式会员（有效期 1 年）
```

## 10. 会员费缴纳（两阶段审核）

### 10.1 费用配置

| 类别 | 默认年费（元） | 说明 |
|------|----------------|------|
| 普通/非学生会员 | 200 | 可按年度后台配置 |
| 学生会员 | 100 | 按用户身份自动匹配 |
| 单位会员 | 5000 | 预留 |

- **每次只能缴纳一年**，不可一次缴 5 年/10 年
- 提前续费：在原有效期基础上**顺延一年**
- 会员费**全站统一一次**，不按分会重复收取

### 10.2 缴费方式

**线下银行转账** → 上传凭证 → 财务审核 → 上传发票 → 财务终审。

> **线上支付**（微信/支付宝等）**不做**（0612 确认：财务核对压力大；继续线下转账 + 上传凭证 + 发票）。

### 10.3 两阶段状态机

```
尚未入会 / 申请已通过
  → 上传凭证 → 凭证初审中
    → 财务初审
      ├── 通过 → 待上传发票（截止日 = 通过日 + 7 工作日）
      │   → 上传发票 → 发票终审中
      │     → 财务终审
      │       ├── 通过 → 会员资格有效（1 年）
      │       └── 驳回 → 发票被驳回 → 重传
      └── 驳回 → 凭证被驳回 → 重传
```

### 10.4 上传要求

| 类型 | 格式 | 大小 |
|------|------|------|
| 缴费凭证 | JPG / PNG | ≤ 5MB |
| 电子发票 | JPG / PNG / PDF | ≤ 10MB，**必传** |

### 10.5 发票宽限期

| 规则 | 说明 |
|------|------|
| 截止日 | 凭证初审通过日 + **7 个工作日**（跳过周六日） |
| 逾期 | 状态变为「发票逾期」，资格锁定，**仍可上传** |
| 提醒 | 距截止 ≤ 3 天发送提醒 |
| 延期 | 总管理员可为单笔记录延长截止日（须记录原因） |

### 10.6 审核规则

- 凭证、发票**分阶段独立审核**
- 驳回**必须填写原因**
- 支持**多选/全选批量审核**
- 验证通过后用户**不可自行修改**；须管理员**手动驳回**后重传
- 会员费与会议费**不可合并支付**

### 10.7 用户可见会员状态

| 状态 | 含义 |
|------|------|
| 尚未入会 | 未开始 |
| 入会申请审核中 | 秘书处审核申请书 |
| 入会申请被驳回 | 可重新申请 |
| 入会申请已通过 | 可缴会费 |
| 凭证初审中 | 财务审凭证 |
| 凭证被驳回 | 可重传凭证 |
| 待上传发票 | 凭证已通过 |
| 发票逾期 | 超期未传发票 |
| 发票终审中 | 财务审发票 |
| 发票被驳回 | 可重传发票 |
| **会员资格有效** | **正式会员** |
| 退会申请审核中 | 秘书处审退会 |
| 已退会 | 可重新入会 |
| 已过期 | 可续费 |

## 11. 分会绑定与管理

### 11.1 核心逻辑

### 11.4 界面要求

- 「专业分会」/「会议绑定管理」：**总学会置顶**，其余 11 个分会在下
- 显示「已绑定 N / 11」

## 13. 参会信息、摘要、住宿与野外报名

### 13.1 前置条件

- 该会议注册费**凭证初审通过**（待上传发票状态）即可填写参会信息
- **报名确认**（发票终审通过）后可下载盖章通知与摘要模板

### 13.2 表单字段

**基础信息**：姓名（可自动填充）、性别（男/女）、单位、身份（教师/学生/嘉宾）

**报告类型**（必填）：

| 类型 | 要求 |
|------|------|
| 口头报告 | 须填报告标题 |
| 展板报告 | 须填报告标题 |
| 仅参会 | 无需标题 |

**摘要上传**：

| 要求 | 说明 |
|------|------|
| 格式 | .doc / .docx |
| 大小 | ≤ 10MB |
| 版本 | **只保留最后一次** |
| 截止 | 摘要截止后不可编辑（管理员可后台代改，须记日志） |

**住宿信息**（0617 性别区分）：

| 选项 | 说明 |
|------|------|

| 女双人间 | — |

**野外报名**（0617，不代收费用）：

### 13.3 修改规则与数据持久化

- 参会信息、摘要文件、住宿与野外选择须**保存至服务端**，与用户、会议报名记录关联
- 截止日期前可多次修改；**只保留最新版本**
- 验证通过后用户不可自行修改；须管理员驳回后重传

### 13.4 后台单场会议统计（0617）

## 14. 会员到期与会议资格处理

### 14.1 会员到期

- 有效期默认自发票确认日起 **1 年**
- 到期后身份降为**非会员**；**分会绑定保留**
- 须重新完成会费两阶段审核以恢复正式会员

### 14.2 到期时会议资格分级（已确认）

**原则**：「已锁定的不追溯，未锁定的清理」

| 到期时会议状态 | 处理 |
|----------------|------|
| 已确认（终审通过） | **资格保留**，照常参会 |
| 发票终审中 | **冻结**；续费并终审通过后自动恢复 |
| 凭证初审中 / 被驳回 / 待传发票 / 逾期 / 发票驳回 | **删除**报名 |

## 19. 智能识别与审计追溯

### 19.1 智能识别（OCR）

| 环节 | 要求 |
|------|------|
| 触发 | 用户上传会费/会议费凭证或发票时 |
| 识别内容 | 金额、付款方、收款方、日期等 |
| 比对 | 与应缴金额、用户信息自动比对 |
| 自动通过策略 | 识别结果与应缴金额一致且无风险提示时，**可自动通过**进入下一状态或终审队列 |
| 人工兜底 | 识别存疑、金额不符、高风险时进入人工审核；管理员可批量处理 |
| 识别结果页 | 供管理员复核，可标注「确认无误 / 有争议」 |

客户要求：「尽量智能审核自动通过，否则秘书处来不及核实」——系统须接入成熟 OCR 服务，在准确率满足阈值时减少人工工作量。

### 19.2 审计追溯

关键操作须落库，**只读查询**，面向用户展示**中文摘要**（非技术字段堆砌）：

| 类型 | 示例 |
|------|------|
| 入会/退会 | 申请审核通过/驳回 |
| 缴费 | 凭证/发票审核 |
| 会议 | 会议费审核 |
| CMS | 发布/下架 |
| 权限 | 管理员分会绑定变更 |
| 识别 | 人工复核 |
| 管理代改 | 摘要/住宿代改、发票延期 |

分会管理员仅见本分会相关记录；财务审核员无审计菜单访问权限。
