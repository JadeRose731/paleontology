***\*中国古生物学会及其分会会员管理系统功能需求\****

 

***\*总体需求：\****

1. 中国古生物学会及其多个学术分会学会网站，均使用单一邮箱统一账号。
2. 中国古生物学会及其多个学术分会设立独立会员费和单次会议注册费，线下财务汇款凭证智能识别，电子发票上传及智能审核（汇款凭证和电子发票这栏请软件公司设计人员关注和沟通），备注：1）需要实时显示各分会每年会员总人数，已缴纳会员费人数，会费笔数。累计计算总会员人数（不重复），总收缴会费总额，总会费笔数。同理，需要实时显示各分会每年会员总人数，单次缴纳会员费人数，单次会议费笔数；累计计算分会会员总人数（不重复），总收缴会议费总额，总会议费笔数。
3. 学术会议参会信息可修改。
4. 根据会议组织原则要求，不允许组织各地旅游风景区野外路线。为避免审计麻烦，因此不设计会议前期、会中和会后野外收缴功能。各会员根据自己需要，自由选择参加会前、会中、和会后野外相关路线，页面内仅提供旅游公司通知公告和联系方式，野外路线及费用由旅游公司统一收取。

 

***\*重点关注：\****

账号唯一原则：一个邮箱对应一个全局唯一账号，全站通用（邮箱不能重复注册）。

权限隔离原则：各级会员费决定各级会议通知原文件和摘要模板可下载，各级会议费决定参会资格并提交各级会议报告信息。

单次缴费原则：各级会员费、会议注册费均只能单笔单次缴纳（方便财务人工审核，如果合并支付会员费和会议注册费，财务人力不足，人工审核困难，系统不能识别会员费信息和会议注册费信息）。

智能和人工审核原则：所有缴费均通过上传凭证(智能识别) + 上传发票（最好做到智能识别和对比），对于需要后台人工审核的部分，请做成多选和全选框，批处理审核合格信息。

最新参会信息版本原则：各级会议参会信息、摘要文件只保留最后一次更新版本。

自动通知原则：所有关键操作（审核结果、信息提交 / 更新）自动发邮件通知。

***\*二、中国古生物学会及分会会员管理与会议费缴纳模块\****

***\*需求：\****

1. 系统支持无限个学术分会，后台可新增 / 编辑 / 禁用。
2. 每个分会独立设置会费金额和有效期（通常 1 年）。
3. 用户可申请加入多个分会，但一次只能缴纳一个分会的会费。
4. 缴费方式：线下银行转账 → 上传缴费凭证（智能识别） + 上传电子发票（智能识别核对） → 财务人工审核

6. 审核驳回需填写原因，用户可重新提交。
7. 会员到期自动失效，需续费才能继续享受分会服务。
